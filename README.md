# 🎬 Movie Explorer

A modern and responsive Movie Explorer web application built using React. This application allows users to explore popular movies, trending content, top-rated movies, upcoming releases, and TV shows.

## 🚀 Features

* 🎬 Browse Popular Movies
* 🔥 View Trending Movies
* ⭐ Explore Top Rated Movies
* 🎥 Check Now Playing Movies
* ⏳ Discover Upcoming Movies
* 📺 Browse Popular TV Shows
* 🔍 Search for Movies and TV Shows
* ❤️ Add Movies to Watchlist
* 📱 Fully Responsive Design
* 🎨 Modern and Attractive User Interface

## 🛠️ Technologies Used

* React.js
* JavaScript
* HTML5
* CSS3
* Bootstrap
* Vite
* TMDB API

## ⚙️ Installation

1. Clone the repository:

```bash
git clone https://github.com/urvashicodes7211/react_project.git
```

2. Go to the project folder:

```bash
cd react_project/movie-explorer
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

## 🌐 API

This project uses the TMDB API to fetch movie and TV show data.
